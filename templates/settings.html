Sauvegarde GitHub

Pourquoi ? Cette sauvegarde pousse une copie de votre base de données (motostock.db) dans votre dépôt GitHub : tout votre travail local est ainsi protégé en ligne et restaurable à tout moment.

Configuration (une seule fois) :
1. Créez un dépôt sur GitHub (ex : -Tumika-backup).
2. Créez un Personal Access Token : GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, cochez repo.
3. Renseignez les champs ci-dessous puis cliquez sur le bouton vert. Pas de token stocké dans la base de données (uniquement dans un fichier local protégé).

Synchronisation automatique (site en ligne)

Sur le site hébergé (Render), l'application récupère automatiquement la base de données poussée sur GitHub et l'affiche : vos données locales sont actualisées en ligne à chaque sauvegarde, sans aucune action manuelle (vérification à chaque requête, limitée à un appel GitHub toutes les {{ sync_interval|default(30) }} secondes).
